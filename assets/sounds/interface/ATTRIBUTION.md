# Interface sound pack

Short UI cues from [Mixkit](https://mixkit.co/free-sound-effects/interface/), used under the [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree). Free for commercial and non-commercial projects. Attribution is appreciated and not required. These files are trimmed, faded, converted to mono, and leveled for in-app cues. They are not redistributed as a stock library.

Settings preview plays the squeeze cue, which is **Software interface remove**.

| Role | Mixkit title | Source |
| --- | --- | --- |
| `prepare.mp3` | Opening software interface | https://assets.mixkit.co/active_storage/sfx/2578/2578.wav |
| `squeeze.mp3` | Software interface remove | https://assets.mixkit.co/active_storage/sfx/2576/2576.wav |
| `rest.mp3` | Software interface back | https://assets.mixkit.co/active_storage/sfx/2575/2575.wav |
| `quickSqueeze.mp3` | Interface option select | https://assets.mixkit.co/active_storage/sfx/2573/2573.wav |
| `complete.mp3` | Software interface start | https://assets.mixkit.co/active_storage/sfx/2574/2574.wav |
