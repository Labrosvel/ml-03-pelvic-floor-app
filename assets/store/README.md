# Store graphics

## Google Play

| File | Use |
| --- | --- |
| `feature-graphic.png` | Feature graphic — English (1024 × 500) |
| `feature-graphic-el.png` | Feature graphic — Greek (1024 × 500) |

Play Console → **Store presence → Main store listing → Feature graphic**.

You can replace these anytime; changes go through publishing review.

Full Play checklist: [`docs/GOOGLE_PLAY.md`](../../docs/GOOGLE_PLAY.md).

## App Store (iOS)

Play feature graphics are **not** App Store screenshots.

Ready-to-upload iPhone screenshots (1179 × 2556 PNG, no personal iPhone needed): **[`ios-screenshots/`](ios-screenshots/)**.

Drag them into App Store Connect → **iPhone with Dynamic Island (medium display)**. Details: [`docs/APP_STORE.md`](../../docs/APP_STORE.md).
